# Dinetap

Dinetap helps restaurants run their floor and reach their guests:

- **Dinetap Hub**: point of sale, kitchen display and back office on any phone, tablet or desktop.
- **Dinetap app**: discover restaurants, pay the bill and earn cashback.
- **Payments** built in, so restaurants get paid in one place.
